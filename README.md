# Парсер статей о старении из pubmed с сохранением в базу данных

Ищет информацию о статьях про старение в pubmed, сохраняет название, дату, ссылку и краткое описание в базу данных PostgreSQL. Сама БД запущена локально на моем ПК через докер контейнер, персональные данные из кода удалены. 

## 🚀 Демонстрация


## 🛠️ Стек технологий
* **Язык программирования: Python, SQL
* **Парсинг и скрапинг:**
  * `BeautifulSoup4` — извлечение и очистка данных из HTML-кода страниц.
  * `requests` — отправка HTTP-запросов к сайту.
  * `fake-useragent` — динамическая подмена заголовков (User-Agent) для обхода базовой защиты от ботов.
* **Базы данных:**
  * `PostgreSQL` — реляционная СУБД.
  * `psycopg2` — модуль для взаимодействия Python-скрипта с базой данных PostgreSQL.
* **Управление процессами:**
  * `time` (встроенный модуль) — регулирование частоты запросов (таймауты) для предотвращения блокировок (Rate Limiting).

## ✨ Основной функционал
Что умеет делать ваша программа (коротко по пунктам):
* 🔹 Нахождение статей в pubmed по заданной теме (старение)
* 🔹 Сохранение информации о статьях (название, год выпуска, ссылка, краткое описание) в базу данных PostgreSQL
